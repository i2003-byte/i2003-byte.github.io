📘 Learn the science

💡 The big idea

One number that describes a whole set of data is called an average, or a measure of central tendency. There are three common ones, and each answers a different question.

The mean shares the total out equally. It is also the balance point: put the dots on a ruler and it balances on a pivot at the mean. The median is the middle value when the data is in order. The mode is the value that turns up most often.

🧮 Key formulas

mean x̄ = (x₁ + x₂ + … + xₙ) ÷ n

Sum of all values divided by how many there are. The distances above and below it always cancel: Σ(x − x̄) = 0.

median = middle value (n odd) · average of the two middle values (n even)

Sort first. For n values the middle one is the ((n + 1) ÷ 2)th.

mode = the most frequent value · range = largest − smallest

A set can have two modes, or none if every value occurs equally often. Range measures how spread out the data is, not an average.

🌍 Real-world examples

  • A cricketer's batting average is a mean: total runs ÷ number of times out.
  • A shoe shop orders the most of the modal size; a mean shoe size like 7.3 is no use to it.
  • The median income of a town is a better “typical” figure than the mean, which a few very rich people pull upwards.

🎯 Try this

  1. With the marks of 9 students, find the mean, median and mode yourself, then check the numbers.
    Show answerSum = 120, so the mean = 120 ÷ 9 ≈ 13.33. Sorted, the 5th value is 14, so the median = 14. The mode is 15 (three times).
  2. Press “Add an outlier” once. Which average moves the most?
    Show answerThe mean jumps from 13.33 to 14.0 (140 ÷ 10). The median only moves from 14 to 14.5 and the mode stays 15. The mean feels every value, so one extreme value pulls it.
  3. Turn on “Show distances from the mean”. Compare the total length on each side. Now drag a dot and look again.
    Show answerThe two sides are always equal, wherever you drag the dots. That is why the line balances on the mean: Σ(x − x̄) = 0.
  4. Drag the dots so that the mean, median and mode are all 10.
    Show answerMany answers. One: 8, 9, 10, 10, 10, 11, 12 — symmetric data with the most dots in the middle has all three equal.
  5. In the Pune rainy-days data, which average best describes a “typical month”? Why?
    Show answerThe months are very uneven: mean ≈ 5.75, median 2.5, mode 0. No single number is “typical” here; the data has a monsoon season and a dry season, so it is better to describe them separately.

📖 Key terms

  • Observation: one value in the data set.
  • Outlier: a value far away from the rest.
  • Dot plot: one dot per value, stacked above its place on a number line.
