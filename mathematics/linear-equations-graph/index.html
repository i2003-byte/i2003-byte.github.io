📘 Learn the science

💡 The big idea

An equation like x + y = 5 has many solutions: (0, 5), (1, 4), (2, 3), (2.5, 2.5)… Plot them all and they make a straight line. That is why ax + by = c is called a linear equation in two variables.

Two such equations together are a pair of linear equations. A solution of the pair has to satisfy both, so it must lie on both lines. Two straight lines on a plane can only behave in three ways:

  • they cross at one point: exactly one solution (the pair is consistent);
  • they are parallel: no solution at all (inconsistent);
  • they are the same line: every point on it is a solution, so infinitely many (dependent, and still consistent).

You can tell which, without drawing, by comparing the ratios of the coefficients. Drag the test point P around to feel what “a solution” means: P turns green only where it fits both equations.

🧮 Key formulas

a₁x + b₁y = c₁ and a₂x + b₂y = c₂ a₁/a₂ ≠ b₁/b₂ → one solution (lines cross) a₁/a₂ = b₁/b₂ ≠ c₁/c₂ → no solution (parallel lines) a₁/a₂ = b₁/b₂ = c₁/c₂ → infinitely many (same line)

Example: x + 2y = 4 and 2x + 4y = 12 give 1/2, 2/4 = 1/2 and 4/12 = 1/3. The first two match but the third does not, so the lines are parallel.

x = (c₁b₂ − c₂b₁) / (a₁b₂ − a₂b₁), y = (a₁c₂ − a₂c₁) / (a₁b₂ − a₂b₁)

This is what the sim uses to find the crossing point exactly, even when it is a fraction such as (25/11, 1/11) that is hard to read off a graph. If a₁b₂ − a₂b₁ = 0 the lines have the same slope.

The ratio test is done by cross-multiplying (a₁b₂ = a₂b₁ means a₁/a₂ = b₁/b₂), so it also works when a coefficient is 0, as in the lines x = 3 and y = −2. The grid shows −8 to 8 only; crossing points outside it are given in words.

🌍 Real-world examples

  • Two shopkeepers' bills for the same two items let you work out each item's price: two equations, one crossing point.
  • Comparing two mobile data plans (a fixed charge plus a rate per GB): the crossing point is the usage at which both cost the same.
  • Two trains on parallel tracks at the same speed never meet: parallel lines on a distance–time graph.
  • Engineers solve thousands of linear equations together to design bridges, electric grids and weather forecasts; the idea is the same as for two.

📖 Key terms

  • Linear equation in two variables: an equation of the form ax + by = c, where a and b are not both zero. Its graph is a straight line.
  • Solution of a pair: values of x and y that make both equations true; the point where the lines meet.
  • Consistent: has at least one solution (lines cross or coincide).
  • Inconsistent: has no solution (parallel lines).
  • Dependent: both equations describe the same line, so there are infinitely many solutions.
