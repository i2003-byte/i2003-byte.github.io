📘 Learn the science

💡 The big idea

A set is a well-defined collection: for any object you can say clearly whether it belongs or not. “Even numbers up to 20” is a set. “Good students” is not, because people will disagree about who is good.

There are two ways to write the same set. The roster form lists every element: A = {2, 4, 6, 8}. The set-builder form gives the rule instead: A = {x : x is an even number less than 10}. A Venn diagram draws it: a rectangle for the universal set U and a circle for each set. Where the circles overlap are the elements that belong to both.

🧮 Key ideas

x ∈ A means “x is an element of A”; x ∉ A means it is not A ⊂ B when every element of A is also in B

Then circle A could be drawn inside circle B, and the “only A” part of the diagram is empty.

∅ = { } the empty set, with no elements
  • n(A) is the number of elements in A (its cardinal number).
  • In roster form each element is written once and the order does not matter: {1, 2, 3} = {3, 1, 2}.
  • Disjoint sets have no element in common, so their circles share nothing.
  • The empty set is a subset of every set, and every set is a subset of itself.

🌍 Real-world examples

  • A school sports teacher keeps two lists, the cricket team and the football team. Students in both lists are in A ∩ B; the teacher must not schedule both matches at the same time.
  • A library catalogue search for “physics books in Hindi” finds the overlap of two sets: physics books and Hindi books.
  • The voters’ list of a ward is a set defined by a rule: citizens aged 18 or more who live in the ward.

🎯 Try this

  1. With “Even numbers and multiples of 3”, place all 20 numbers and press Check my sets. Which numbers go in the middle, and why?
    Show answer6, 12 and 18. They are even and also multiples of 3, so they belong to both A and B: they are the multiples of 6.
  2. Where does 7 go? And 1?
    Show answerOutside both circles but inside the rectangle. 7 and 1 are in U (the numbers 1 to 20) but are neither even nor multiples of 3.
  3. Choose “Class 7B: cricket and football players”. Write A in roster form. Who plays both games?
    Show answerA = {Aarav, Diya, Rohan, Sana, Zoya, Arjun}, so n(A) = 6. Aarav, Rohan and Arjun play both, so they go in the overlap.
  4. Choose “Multiples of 4 and even numbers”. After you place everything, which part of the diagram is empty? What does that tell you?
    Show answerThe “only A” part is empty: every multiple of 4 is even. So A ⊂ B, and circle A could be drawn inside circle B.
  5. Choose “Even primes above 2”. How many numbers go in A?
    Show answerNone. The only even prime is 2, so A = ∅, the empty set, and n(A) = 0. A set given by a rule can be empty.

📖 Key terms

  • Element: one member of a set.
  • Universal set (U): the set of everything being talked about in a problem, drawn as the rectangle.
  • Subset: A is a subset of B if nothing in A is outside B.
  • Finite set: a set whose elements can be counted to an end, like these; {1, 2, 3, …} without end is infinite.
